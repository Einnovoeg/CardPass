# Changelog — CardPass

All notable changes are documented here.

## [2.0.0] — 2026-09-05

### Added
- Reader selection for multiple readers
- Configurable auto-type delay

### Fixed
- Layout issues where text could overlap
- Support for different PC/SC readers
- Cases where two readers could show “No readers”
- Window moving to the background after a card is read
- Reader selection not updating the displayed data

### Changed
- Documentation updates
- Build configuration updates

[2.0.0]: https://github.com/Einnovoeg/CardPass/releases/tag/v2.0.0

## [1.0.1] — 2026-09-03

### Added
- Customizable auto-type delay
- Advanced pane

### Fixed
- Device Control permission handling on macOS Tahoe

## [1.0.0] — 2026-09-03

### Added
- Native macOS app with menu bar and Dock support
- Universal card reading
- Clipboard and auto-type support
- Password encoding and hashing

[1.0.0]: https://github.com/Einnovoeg/CardPass/releases/tag/v1.0.0
